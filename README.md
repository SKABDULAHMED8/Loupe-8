# 📌 About Loupe

**Loupe** is a simple browser-based image utility application created to make everyday image-processing tasks easier.

Instead of installing a full image-editing application for basic operations, Loupe lets you work with images directly in your browser.

With Loupe, you can:

- 📐 Resize images
- 📦 Compress images
- ✂️ Crop images
- 🔄 Rotate images
- ↔️ Flip images
- 🔁 Convert images
- 👁️ Preview processed images
- 💾 Download processed images

### 🌐 Live Website

👉 **[Open Loupe](https://loupe-8-image-resizer.edgeone.dev)**

---

# 🎯 Why Was Loupe Created?

Many everyday image tasks do not require professional image-editing software.

You may simply need to:

- Reduce an image's file size before uploading it
- Change an image's dimensions
- Crop an unwanted portion
- Rotate an incorrectly oriented image
- Flip an image
- Convert an image into another supported format
- Prepare an image before uploading it somewhere

Loupe brings these common operations together in one focused browser application.

> **Upload → Choose → Adjust → Preview → Download**

# 🛠️ What Can You Do With Loupe?

## 📐 Resize

Change the width and height of an image according to your requirement.

Useful for:

- Job applications
- Online forms
- Education portals
- Websites
- Documents
- Profile images
- General image preparation

---

## 📦 Compress

Reduce the file size of an image to make it easier to upload, store, or share.

Loupe works toward the selected file-size target while attempting to preserve useful image quality.

> The selected size is a target/maximum and is not a guarantee of an exact final file size.

---

## ✂️ Crop

Remove unwanted areas from an image and keep only the part you need.

Useful for:

- Profile pictures
- Documents
- Presentations
- Websites
- Social media content
- General image editing

---

## 🔄 Rotate & Flip

Correct the orientation of an image or create a mirrored version.

Useful when an image:

- Is sideways
- Needs a different orientation
- Needs to be mirrored

---

## 🔁 Convert

Convert an image into a supported output format.

This can be useful when another website, application, or workflow requires a particular image format.

# 🔐 Privacy-Focused Processing

Loupe is designed around browser-side image processing.

The image-processing workflow is performed locally in the browser rather than requiring the image to be uploaded to a Loupe image-processing server.

> **Your image is processed in your browser.**

External services, hosting infrastructure, browsers, extensions, or third-party resources may have their own policies and technical behavior.

# 🧑‍💻 Technology

Loupe is a browser-based application built using standard web technologies:

- HTML
- CSS
- JavaScript
- Browser APIs
- Canvas-based image processing
- Local browser storage for applicable application features

The project is centered around a simple:

`index.html`

web application.

---

# 🛡️ Processing & Browser Limitations

Browser-based image processing depends on the device and browser's available memory and processing resources.

Very large files or images with extremely large pixel dimensions may not be suitable for processing.

Loupe handles invalid, unsupported, oversized, or unreadable image inputs rather than attempting to process every input blindly.

Animated GIFs may become a still image when canvas-based image processing is performed.
