Can I compress an image to an exact KB size?

Set a maximum size in KB. Loupe searches for the highest JPG or WebP quality that stays at or below that limit. If quality reduction is not enough, it also reduces the pixel dimensions. The final file can be smaller than the limit; the maximum-size setting is not a promise of an exact file size.

Can I resize an image to exact pixel dimensions?

Yes. Enter the target width and height in pixels. With Keep proportions enabled, Loupe adjusts the other dimension to preserve the image shape. With it disabled, Loupe crops to the requested dimensions instead of stretching the image.

Which image formats does Loupe support?

Loupe accepts JPG, PNG, WebP and GIF images. You can export as JPG, PNG or WebP. An animated GIF is processed as a single still image.
