How to resize and compress an image for an online form

Use Loupe-8 to set an image's pixel width and height, crop it to the required frame, and apply a maximum or minimum JPG file-size value. The correct values must come from the form where you will upload the image.

First copy the image rules from the application form. You need the required pixel width and height, accepted file format, minimum and maximum file size, and DPI only when the form specifies it. Then set those values in Loupe-8 and verify the downloaded file.

1. Read the form's image instructions

Record each requirement before editing. Do not assume that all recruitment forms, passport workflows or government portals use the same size. Some forms specify pixels; others give a size range in KB, a format, a background rule or a separate photo-capture process. Use the current notice or upload page for the exact application.

RequirementWhat to record
DimensionsExact width and height in pixels, if the portal gives them.
File sizeMinimum and maximum KB values. Do not treat a maximum as an exact target.
FormatJPG/JPEG, PNG or WebP, exactly as accepted by the portal.
DPIOnly record a DPI value when the instructions require it.
Photo rulesBackground, framing, face position and whether an uploaded file is required.

2. Resize to the required pixel dimensions

  1. Open the Loupe-8 image editor and select your existing photo or scanned image.
  2. Choose Resize and enter the required width and height in pixels.
  3. Keep proportions enabled when you want to preserve the image's full shape. If you turn it off, Loupe crops to the exact frame rather than stretching the picture.
  4. Use Zoom and Move to choose which part of the image stays in the crop.

3. Set the file-size limits

In Resize, the optional minimum and maximum size fields apply to JPG output. Loupe adjusts JPG quality to meet a maximum while keeping the requested pixel dimensions. If the image still exceeds that maximum at those dimensions, Loupe reports that it could not reach the limit. It does not silently change your requested dimensions in this Resize workflow.

The separate Compress tool works differently: it reduces quality and can reduce pixel dimensions step by step when needed to meet the maximum. A maximum is a ceiling, so the result may be smaller than the number you entered.

For a minimum JPG file size, Loupe can add non-image data without changing the visible picture. That padding does not improve image quality and may not satisfy every portal's file validator. Use it only when the application explicitly requires a minimum size.

4. Export and verify the result

  1. Select the required output format. Do not choose WebP when the form accepts only JPG or PNG.
  2. Set DPI only when the portal asks for it. Loupe writes DPI metadata to JPG files only.
  3. Review the preview and download the result.
  4. Open the downloaded file and check its actual pixel dimensions, file format and file size before you upload it.

Does a matching pixel size guarantee acceptance?

No. A portal may also validate file format, minimum or maximum size, background, photo content, naming rules or other conditions. A 35:45 crop option is only an aspect ratio. It does not certify that a photo meets a passport or recruitment requirement. Loupe-8 is an independent image utility, not a government service or application validator.
