Prepare a photo and signature for a government job application

Prepare existing photograph and scanned-signature files for a recruitment form. Loupe-8 can crop, resize, compress and convert image files in your browser. It does not fill in or submit the job application.

Check the current recruitment notice first. There is no single photo size, signature size, pixel dimension, file format or KB limit for every Indian government job application. Requirements can differ by authority, examination, post and recruitment cycle.

Which recruitment application tasks can Loupe-8 help with?

This guide is relevant when you prepare an image upload for an application associated with SSC, UPSC, IBPS, Railway Recruitment Boards (RRB), a State Public Service Commission or another recruitment authority. Search phrases such as “SSC photo signature size”, “UPSC photo upload”, “IBPS signature image” and “RRB application photo size” do not describe one shared specification. Always use the instructions for the exact vacancy and application cycle.

Some portals ask for a photograph file. Others capture a live photograph through the application page or require a different identity-photo workflow. When the portal asks you to capture a live photo, use that feature. Do not substitute an edited file.

Step 1: Read the image instructions in the official notice

Before editing, record the requirements separately for the photograph and the signature:

  • Required file format, such as JPG or JPEG, PNG, or another listed format.
  • Minimum and maximum file size. A maximum KB limit is not the same as a required exact file size.
  • Required pixel width and height, aspect ratio, or physical dimensions, if stated.
  • Photo background, framing, face visibility, signature colour and other image conditions.
  • Whether the portal expects an uploaded file or a live camera capture.

Do not copy dimensions from an old recruitment notice, a different examination or a third-party blog. Save the official instructions for the current application so you can compare the exported file before upload.

Step 2: Prepare the photograph in Loupe-8

  1. Open the Loupe-8 image editor and choose the original photograph, if the application accepts an uploaded photo.
  2. Use Crop to set the ratio or framing only when it matches the official instructions. Keep the face and other required details visible.
  3. Enter the exact pixel width and height when the notice provides them. Do not assume the Passport 35:45 crop option applies to a recruitment form.
  4. Choose a permitted output format. Use Compress to set the stated maximum KB limit for JPG or WebP output when the form accepts that format.
  5. Preview the result, download it and check the exported file's actual dimensions, format and size.

Step 3: Prepare the scanned signature

  1. Use a clear scan or photo of your own handwritten signature. Loupe-8 does not create, draw, imitate or certify a signature.
  2. Crop the existing signature image according to the portal's instructions. Keep the full signature visible and avoid cutting off strokes.
  3. Set the required pixel dimensions and file-size limit. Select only a file format accepted by the application.
  4. Open the downloaded result and compare it with the portal's sample and upload rules.

Check the official recruitment instructions

  • Staff Selection Commission (SSC): use the current examination notice and application instructions. Some SSC workflows require live photo capture.
  • UPSC online application FAQ: see the Commission's instructions for photograph, signature and document uploads.
  • Institute of Banking Personnel Selection (IBPS): open the relevant CRP or recruitment notice and its image-upload instructions.
  • Indian Railways official website: use the relevant Railway Recruitment Board's current notification and application portal.

These links are starting points for official information, not a statement that one set of upload limits applies across every recruitment. Read the current notice and the instructions displayed in the actual application portal.

Frequently asked questions

What is the photo size for an SSC, UPSC, IBPS or RRB application?

There is no universal number. Each recruitment notice can specify its own dimensions, file format and file-size range. Some workflows use live photo capture. Check the exact current notice and portal instructions.

Can I use the same photo and signature file for every government job?

Only when the current application instructions match the file's dimensions, format, size and image conditions. Recheck each application instead of reusing a file automatically.

Can Loupe-8 submit my job application?

No. Loupe-8 prepares image files only. You must complete the official application form and submit it on the recruitment authority's website.

Does Loupe-8 change the photo background or create a signature?

No. It can crop, resize, compress and convert an existing image. It does not replace the background or create a handwritten signature.
