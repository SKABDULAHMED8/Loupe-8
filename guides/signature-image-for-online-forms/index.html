How to resize a scanned signature for an online application

Loupe-8 can resize an existing scanned signature image by pixel dimensions, crop it, convert its format and set minimum or maximum JPG file-size limits. It does not create, draw or apply a digital signature.

Start with the form's instructions. Note the required image format, pixel dimensions and minimum / maximum file size. These values are not the same for every examination or portal.

Steps to resize a signature image

  1. Write your signature on paper using the method required by the application, then scan or photograph it clearly.
  2. Open the Loupe-8 editor and choose the existing JPG, PNG or WebP image.
  3. Use Crop if you need to remove excess blank margins. Keep the signature itself intact and legible.
  4. Select Resize and enter the required width and height in pixels.
  5. If the portal specifies a maximum file size, use Maximum size in KB. If it specifies a minimum too, enter both limits and read the tool's note about minimum-size padding.
  6. Export in the format required by the portal. Open the downloaded file and verify its dimensions and size.

Example: UPSC online application instructions

The UPSC online application FAQ currently describes a specific photo / signature requirement: JPG/JPEG format, a file size from 20 KB to 300 KB, and width and height from 350 pixels minimum to 1000 pixels maximum. This is an example for the UPSC application guidance checked on 26 November 2026. It is not a universal requirement for SSC, Passport Seva or other forms.

Important: resizing is not signing

Loupe-8 only edits an image file that you select. It does not draw a signature, sign a form, apply a certificate-based digital signature or verify the identity of the person who signed the paper.

Supported file handling

  • Input: JPG, PNG, WebP and GIF. An animated GIF is processed as a still image.
  • Output: JPG, PNG and WebP.
  • DPI metadata: written to JPG exports only.
  • Minimum JPG file size: Loupe-8 may add non-image data to meet a configured minimum; the visible image does not change because of that padding.

For a government application, follow the latest official instructions for the specific exam or department. A specification from one authority should not be copied to another application without checking its notice.

Reviewed: 26 November 2026. Application requirements can change. Always check the current instructions published by the portal where you will submit your image.
