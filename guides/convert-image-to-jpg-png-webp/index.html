How to convert images to JPG, PNG or WebP

Loupe-8 converts an image to JPG, PNG or WebP in your browser. Select the output format that the destination website accepts, then preview and download the new file.

To convert an image with Loupe-8: open the editor, choose an image, select Convert, choose JPG, PNG or WebP, then download the result. Check the exported file's format and size before using it.

Which image format should you choose?

FormatUseful whenImportant detail
JPG/JPEGPhotographs and forms that request JPEG.JPG does not support transparency. Loupe fills transparent areas with white when exporting to JPG.
PNGGraphics, screenshots or images that need transparency.PNG is not a JPG file-size substitute; check the portal's size limit after export.
WebPWebsites or services that explicitly accept WebP.Do not choose WebP for a form that lists only JPG/JPEG or PNG.

Convert an image in Loupe-8

  1. Open the Loupe-8 image editor and choose a JPG, PNG, WebP or GIF image.
  2. Select Convert in the tool tabs.
  3. Choose JPG, PNG or WebP as the output format.
  4. Check the preview. For a JPG export, transparent image areas become white.
  5. Download the new image and verify the file extension, format, pixel dimensions and file size.

What happens to GIF animation?

Loupe reads an animated GIF as a single still image. It does not preserve the animation when processing the GIF in the image editor. Choose another tool if you need to keep multiple animation frames.

Does conversion preserve camera or image metadata?

Do not rely on EXIF or other original embedded metadata being preserved. Loupe renders the selected image in the browser and exports a new image file. If you need a DPI value, use the DPI control in Resize; Loupe writes that metadata into JPG exports only.

Will the converted image be accepted by an online form?

Not automatically. A portal may accept only one or two formats and may also check pixel dimensions, file size and image content. Follow the current instructions for the specific form. A successful conversion only changes the output file; it does not validate the application requirements.

Before you submit

  • Confirm the exact accepted format in the portal instructions.
  • Check the actual dimensions and file size of the downloaded file.
  • Open the export to check transparency, background and visual quality.
  • Keep an original copy of the source image in case you need a different format later.
