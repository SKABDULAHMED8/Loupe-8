How to compress an image to 20 KB or 50 KB

Use Loupe-8 to compress a JPG or WebP image to a maximum file-size limit such as 20 KB or 50 KB. The tool searches for an acceptable quality and can reduce pixel dimensions when quality reduction alone is not enough.

A maximum is a limit, not an exact target. A file set to a 20 KB maximum can finish below 20 KB. Loupe-8 does not promise an output of exactly 20 KB or exactly 50 KB.

Steps to compress the image

  1. Open the Loupe-8 editor and select the image.
  2. Choose Compress.
  3. Enter 20 or 50 in Maximum size in KB, based on the form's stated limit.
  4. Select JPG or WebP if the application accepts that format.
  5. Review the generated preview and file information.
  6. Download the result and confirm its file size and format before uploading.

What if the form gives a minimum and a maximum?

Use both fields only when the application specifies both limits. Loupe-8 can reduce image quality to meet a maximum. For a configured minimum JPG size, it can add non-image data so the file reaches the minimum without changing the visible picture. This padding is not a way to improve image quality. It only changes the file size.

Example from the UPSC online application FAQ

The UPSC FAQ currently gives a photo / signature example of 20 KB minimum and 300 KB maximum, with JPG/JPEG format and width and height between 350 and 1000 pixels. That is the published example for the UPSC application guidance checked on 26 November 2026. Do not apply it automatically to another examination or portal.

Why can the output be smaller than the limit?

The final size depends on image dimensions, visual detail, format and compression quality. If the selected image already fits under the maximum, Loupe-8 does not need to enlarge it just to approach the limit. Use a separate minimum-size value only when the form specifies one.

Never assume that 20 KB or 50 KB is the correct value for every government form. Check the live upload instructions and verify the downloaded file before submitting it.
