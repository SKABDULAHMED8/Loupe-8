How to crop a passport-style photo for an online form

Use Loupe-8 to crop an existing photo to a supported aspect ratio, set pixel dimensions and export the image in a supported format. The result is a prepared image file, not a guarantee that a passport or recruitment portal will accept it.

Important: Loupe-8's Passport 35:45 option sets a 35:45 crop ratio. It does not set a universal Indian passport-photo specification or change the photo background. Follow the exact instructions for your application.

How to prepare the photo in Loupe-8

  1. Open the Loupe-8 editor and choose an existing photo.
  2. Select the Crop tool and choose the Passport 35:45 aspect ratio only when it matches the form instructions.
  3. Adjust the Zoom and Move controls so the required part of the original photo remains in the frame.
  4. Enter the pixel width and height, file-size limit and output format specified by the portal.
  5. Preview the result, download it and check the downloaded file's dimensions and size before uploading it.

Does 35:45 mean every Indian form needs that ratio?

No. A 35:45 ratio is one crop option in Loupe-8. Different government services, recruitment examinations and private portals can specify different dimensions, file formats, backgrounds and size limits. Some Passport Seva application workflows capture a photograph at a Passport Seva Kendra instead of asking the applicant to upload a digital photo. Do not assume the same rule applies to every service.

Check the official requirement first

  • Passport Seva: official application information.
  • Staff Selection Commission: current notices and application instructions.
  • UPSC online application FAQ.

Check the current notification or application page for the required photo ratio, pixel width and height, file size, file format, background, framing and any photo-capture rules. Loupe-8 is not an official government portal.
