Free online image resizer and compressor for forms

Loupe-8 is a free browser-based image resizer, compressor and converter. It lets you enter exact pixel dimensions, crop an image, set a maximum file size in KB, and export JPG, PNG or WebP files. Use it to prepare an existing photo, scanned signature or profile picture before an online upload.

Quick answer: Use Resize when a form gives pixel width and height. Use Crop when the image needs a specific shape. Use Compress when the form sets a maximum file size. Use Convert when the portal requires JPG, PNG or WebP. Loupe-8 processes the selected image in your browser.

How do I resize an image to exact pixels?

Open the Loupe-8 image editor, choose an image, select Resize and enter the required width and height in pixels. Keep proportions enabled to preserve the original shape. Turn it off when you need Loupe-8 to crop to the exact target frame. Use the Zoom and Move controls to choose which part stays visible. Preview the result and verify the downloaded pixel dimensions.

How do I compress an image to a KB limit?

Select Compress and enter the maximum file size required by the upload form. Loupe-8 searches for the highest JPG or WebP quality that stays at or below that maximum. If quality reduction is not enough, it also reduces the pixel dimensions. The output can be smaller than the maximum. A 20 KB maximum does not mean the downloaded file will be exactly 20 KB.

If a form specifies both a minimum and a maximum JPG size, enter both limits only when the current form instructions require them. Loupe-8 can add non-image data to meet a configured minimum JPG size. This padding changes the file size, not the visible image quality.

How do I crop a photo for an online application?

Choose Crop and select a supported ratio such as Square 1:1, Passport 35:45, Portrait 3:4 or Portrait 4:5. Adjust Zoom and Move to position the subject. An aspect ratio controls the shape of the crop; it does not confirm that a photo meets a particular passport, recruitment or government specification. Check the current official instructions for the application.

Can I resize a scanned signature?

Yes. Loupe-8 can resize and crop an existing scanned signature image. Enter the dimensions and file-size limits stated by the application, export in the required format, and check the downloaded file. Loupe-8 does not draw a signature, create a digital signature, apply a certificate, or sign a PDF.

Are images uploaded when I use Loupe-8?

The selected image is processed locally in the browser and is not uploaded to a Loupe image-processing server. The page loads Google Fonts, and the hosting provider may keep standard server logs. Read the site's Privacy Policy for the full details of external requests and browser-local data.

What can Loupe-8 not do?

  • It does not guarantee acceptance by a government, recruitment, education or private portal.
  • It does not remove or replace photo backgrounds.
  • It does not create a new photograph or digital signature.
  • It does not submit the finished image to another website.
  • It cannot add real image detail when a small image is enlarged.

How to prepare an image in six steps

  1. Open the Loupe-8 editor and select an existing image.
  2. Choose Resize, Compress, Convert or Crop.
  3. Enter the dimensions, format and file-size limits shown by the destination form.
  4. Adjust the crop position if needed.
  5. Preview the result and download the image.
  6. Open the downloaded file and verify its dimensions, format and file size before uploading.
