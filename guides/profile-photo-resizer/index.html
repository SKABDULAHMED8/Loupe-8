How to crop and resize a profile picture

Use Loupe-8 to crop an existing profile photo to a square 1:1 shape or another supported aspect ratio, enter custom pixel dimensions and export the image as JPG, PNG or WebP.

There is no single profile-picture size for every app. Check the current image dimensions and file-size rules for the website or social platform where you will use the picture.

Make a square profile picture

  1. Open the Loupe-8 editor and choose your photo.
  2. Select Crop and choose Square 1:1.
  3. Use Zoom and Move to position the face or subject inside the crop.
  4. Enter the pixel dimensions required by the destination platform.
  5. Select an accepted output format and file-size limit.
  6. Preview the final crop and download it.

Check the destination platform

Profile-image display sizes and accepted formats can change. Do not assume that one pixel dimension works for WhatsApp, Instagram, Facebook, LinkedIn, Google accounts and every other service. Use the current help page for the service you are updating.

What Loupe-8 changes

  • Crop ratio and crop position.
  • Pixel width and height.
  • Maximum JPG or WebP file size.
  • Image output format, rotation and flipping.

Loupe-8 does not create a profile, upload the image to the destination platform, remove backgrounds or apply filters. Image processing is performed in your browser.

Before uploading, open the downloaded file and check that it looks clear at the intended display size. A crop that fits one profile layout can need a different framing for another service.

Reviewed: 26 November 2026. Application requirements can change. Always check the current instructions published by the portal where you will submit your image.
