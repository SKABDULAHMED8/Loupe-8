How to resize an image to exact pixel dimensions

Loupe-8 lets you enter a target width and height in pixels. Keep proportions enabled to preserve the image shape. Turn it off when you need to crop the image to the exact frame instead of stretching it.

For a form upload, use the exact pixel width and height written in that form's instructions. Do not substitute centimetres, aspect ratios or DPI for pixel dimensions unless the portal explicitly allows it.

Resize an image in Loupe-8

  1. Open the Loupe-8 editor and select an image.
  2. Choose Resize or the Crop tool if you need to control which part remains in the frame.
  3. Enter the required width and height in pixels.
  4. Keep proportions enabled if you want to preserve the full image shape. If you disable it, Loupe crops to the requested frame rather than stretching the image.
  5. Use Zoom and Move controls to position the crop.
  6. Preview and download the output, then verify the actual pixel dimensions.

Pixel dimensions, aspect ratio and DPI are different

SettingWhat it controls
Pixel width and heightThe number of pixels in the exported image.
Aspect ratioThe relationship between image width and height, such as 1:1 or 35:45.
DPI metadataA print-resolution metadata value. Loupe-8 writes the selected DPI into JPG files only.
File size in KBThe storage size of the exported file, which depends on dimensions, format and compression.

Does exact resizing guarantee application acceptance?

No. The portal can also check file size, format, background, content, naming rules or other requirements. Loupe-8 is an image utility, not an application validator. Always compare the downloaded file with the current official instructions.

Use the current application notice for the exact output dimensions. Requirements can change between examinations, application years and portals, including when the same authority runs different forms.
